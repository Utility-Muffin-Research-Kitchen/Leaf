Mupen64Plus Standalone for Leaf / MLP1
======================================

This packaged path core is built by the UMRK N64-standalone sibling repo from:

  https://github.com/josegonzalez/minui-n64-pak
  upstream ref: c3a90408ec93f44b3a5b47e828c3fc69f95c091e

The Leaf package is a combined payload. Component provenance:

  minui-n64-pak wrapper and embedded overlay adaptation
    License: MIT
    Source: https://github.com/josegonzalez/minui-n64-pak

  Mupen64Plus core, ui-console, audio-sdl, input-sdl, rsp-hle, video-rice
    License: GPL-2.0 with component notices in each upstream LICENSES file
    Source:
      https://github.com/mupen64plus/mupen64plus-core
      https://github.com/mupen64plus/mupen64plus-ui-console
      https://github.com/mupen64plus/mupen64plus-audio-sdl
      https://github.com/mupen64plus/mupen64plus-input-sdl
      https://github.com/mupen64plus/mupen64plus-rsp-hle
      https://github.com/mupen64plus/mupen64plus-video-rice

  GLideN64, when built with MLP1_BUILD_GLIDEN64=1
    License: GPL-2.0 with bundled third-party notices
    Source: https://github.com/gonetz/GLideN64

  7-Zip standalone 7zzs binary
    License: LGPL-2.1-or-later, LGPL with unRAR restriction for some code,
      BSD-3-Clause for some code, BSD-2-Clause for some code
    Source: https://github.com/ip7z/7zip
    The package also includes lib/7zzs.LICENSE from the upstream binary tarball.

  SDL2, SDL2_ttf, FreeType, HarfBuzz, libpng, zlib, libstdc++, libgcc_s
    License: see each upstream project license
    Source: copied from the UMRK MLP1 Buildroot toolchain sysroot.

The N64-standalone package manifest records the exact bundled library sonames.
The source checkout used for the build contains the verbatim GPL/LGPL, zlib, and
7-Zip license texts under workdir/mlp1/src after `make package-mlp1`.
